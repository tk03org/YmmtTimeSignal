# 夢限大みゅーたいぷ 時報ツール (YmmtTimeSignal)

夢限大みゅーたいぷ（ゆめみた）各メンバーの時報ボイスを、指定の間隔（毎時0分など）でランダム再生するWindowsタスクトレイ常駐ツールです。

## 主な機能

- **タスクトレイ常駐型**：タスクバーを邪魔せずバックグラウンドで軽快に動作します。
- **柔軟な再生間隔**：
  - 60分おき（毎時0分）
  - 30分おき / 20分おき / 15分おき / 10分おき
- **キャラクター個別選択**：
  - 流したいメンバーを個別にON/OFF可能。
  - 同一時間帯（同じ「○時」の間）では同一キャラクターが連続しないようランダム抽選。
  - 音声フォルダが配置されていないキャラクターは自動で「（未導入）」表示となり誤動作を防止。
- **音量ブースト＆リミッター**：
  - 通常音量（20%〜120%）に加え、聞き取りやすい音量ブースト（150% / 200%）を搭載。
  - 200% / 150% 設定時は音割れ防止ソフトリミッターが自動作動。
- **手軽なテスト再生**：
  - トレイアイコンのダブルクリック、または右クリックメニューから現在時刻の時報ボイスを即座に確認可能。
- **Windows起動時自動スタート**：
  - レジストリ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）を利用した自動起動設定に対応。
- **一時ミュート機能**：
  - 会議中や集中したいときにワンクリックで時報を一時停止（アイコンにミュート斜線が表示されます）。
- **指定時間停止（スケジュール停止）**：
  - 就寝中や決まった会議時間など、任意の時間帯（または特定時刻）に時報を自動停止可能（最大3枠）。
  - 「含む / 含まない」トグル、日付またぎ対応、特定時刻のみ停止スイッチ、および「1回のみ / 繰り返す」トグルスイッチを搭載。
  - メニューから各枠をワンクリックでON/OFFでき、停止期間中はトレイアイコン（三日月バッジ）でお知らせ。

## 使い方

### 1. 音声フォルダの配置
実行ファイル（`YmmtTimeSignal.exe`）と同じフォルダ、またはそのサブフォルダに購入・展開した音声フォルダ（`b587xxxx`）をそのまま配置します。

```text
配置例:
├── YmmtTimeSignal.exe
├── b5872132/        (仲町あられ 音声フォルダ)
├── b5875332/        (宮永ののか 音声フォルダ)
├── b5875940/        (峰月律 音声フォルダ)
├── b5875983/        (藤都子 音声フォルダ)
└── b5879957/        (千石ユノ 音声フォルダ)
```

### 2. 起動
`YmmtTimeSignal.exe` を起動すると、Windows右下のタスクトレイ（通知領域）に時計アイコンが表示されます。

### 3. 操作方法
タスクトレイのアイコンを右クリックしてコンテキストメニューから操作します：

| メニュー項目 | 内容 |
| :--- | :--- |
| **各キャラクター** | チェックを付けたメンバーの中からランダムに時報が選ばれます。 |
| **再生間隔** | 60分 / 30分 / 20分 / 15分 / 10分 から選択できます。 |
| **音量** | 20%〜200% から設定できます（150%以上はリミッター付）。 |
| **指定時間停止** | 登録したスケジュール（枠1〜3）のON/OFF切り替えや設定ダイアログを開きます。 |
| **一時ミュート** | チェックを入れると時報再生を一時停止します。 |
| **今すぐテスト再生** | 現在時刻のボイスをテスト再生します（アイコンのダブルクリックでも可）。 |
| **Windows起動時に自動起動** | PC起動時に自動常駐させる設定を切り替えます。 |
| **音源フォルダを再読み込み** | 起動後に音声フォルダを追加・変更した際に再スキャンします。 |
| **終了** | アプリを終了します。 |
